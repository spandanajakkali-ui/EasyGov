# EasyGov

Accessible Government Services for Everyone

## Problem
Many citizens face accessibility barriers when interacting with government forms:
- Complex language
- Lack of multilingual support
- Difficult navigation for people with disabilities
- Limited compatibility with assistive technologies

## Solution
EasyGov is a guided government form assistant designed to make services accessible for everyone.  
It provides step-by-step guidance, simple explanations, and accessibility features to ensure inclusivity.

## Key Features
- 🌐 Multilingual interface (English + Kannada support)
- 🔊 Read Aloud functionality
- 🔤 Text-size adjustment
- 🎨 High contrast mode
- 🧭 Step-by-step guidance
- ✍️ Simple explanations
- 🤖 AI accessibility assistant
- 📱 Responsive design
- ⌨️ Keyboard-friendly navigation

## Technology
- HTML  
- CSS  
- JavaScript  
- Web Speech API (for Read Aloud)  
- GitHub Pages (for deployment)
